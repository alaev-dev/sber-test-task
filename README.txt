"Для запуска проекта используется сторонняя библиотека для создания приложения в docker контейнере."

Все настройки уже внедрены в данный проект, необходимо только запустить sber-test-task -> Tasks -> jib ->
jibDockerBuild.

Не обращаем внимания на ошибку билда,
которая появляется после создания контейнера.

Дожидаемся создания контейнера и запускаем проект через docker-compose.yaml файл.

В проект внедрен swagger который можно подключит по порту 8082 или просто ввести в браузере данную ссылку
http://localhost:8082/swagger-ui/index.html#/

К кафке можно обратиться только через ui.
